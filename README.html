Lyrae – Steuerung

Kurzer Einstieg in alle Tasten und Mausbefehle.

Alle Befehle mit Mauszeiger (Phaser, Torpedos, Strahlen, Kurs) zielen auf die Stelle, an der sich der Mauszeiger gerade befindet.

Fliegen

RechtsklickKurs in Richtung Mauszeiger setzen – funktioniert in der Spielansicht und auf der Minimap. Bei hoher Geschwindigkeit dreht das Schiff langsamer.
0 … 9Geschwindigkeit 0–9
Shift+1 … 3Geschwindigkeit 10–12 (falls das Schiff so schnell ist)
MausradGeschwindigkeit stufenweise erhöhen / verringern
LZiel festlegen (Lock): Mauszeiger auf der Minimap über einem Planeten → Kurs auf den Planeten; in der Spielansicht über einem Schiff in Scanreichweite → Schiff verfolgen. Erneut L hebt den Lock auf. Manueller Kurs oder Geschwindigkeit beendet ihn ebenfalls.
OIn den Orbit eines Planeten gehen (langsam fliegen und den Planeten berühren)
Shift+DAn einer Sternenbasis andocken

Kampf

LinksklickPhaser auf den Mauszeiger – sofort, kurze Reichweite, mehr Schaden aus der Nähe
FPhotonentorpedo in Richtung Mauszeiger
Shift+FPlasmatorpedo auf den Mauszeiger (nur Schiffe mit Plasma)
DEigene Torpedos zünden, z. B. wenn sie vorbeifliegen würden
LeertasteGegnerische Torpedos in der Nähe vorzeitig zünden (weniger Schaden). Gedrückt halten zeigt den Wirkungsbereich.
SSchild an / aus – kostet Energie, schützt die Hülle
CTarnung an / aus – unsichtbar für Gegner, aber keine Waffen und Strahlen
TTraktorstrahl (ziehen) auf den Mauszeiger an / aus
PPressorstrahl (stoßen) auf den Mauszeiger an / aus

Planeten erobern

BGegnerischen Planeten im Orbit bombardieren (vernichtet Armeen)
↑Armeen von eigenem Planeten an Bord holen an / aus (benötigt Kills)
↓Armeen auf den Planeten absetzen an / aus

Schiff und Anzeige

RReparaturmodus – im Stillstand oder Orbit; endet bei Geschwindigkeitsänderung
Shift+RRefit-Panel ein / aus – Schiffstyp wechseln (Orbit an eigenem Kernplaneten, Schiff zu 75 % intakt)
TabTeamliste und Nachrichten ein- / ausblenden

Allgemein und Menüs

Tab / Shift+TabIn Menüs zum nächsten / vorherigen Eingabefeld oder Knopf
EnterAusgewählten Knopf bzw. Eingabe bestätigen
Alt+EnterVollbild an / aus
Strg+QSpiel beenden
